# ADR-007: Desktopローカル保存の一元化（~/deskspawn）

## Status
accepted

## Context
デスクトップ版は旧実装で、プロジェクト保存先が実行時カレントディレクトリ（cwd）に依存していた。実行環境によっては一時ドライブ（B: 等）に解決され、ユーザーデータが不安定な場所に保存されるリスクがあった。また、プロジェクト・設定・テンプレート・ツールが散在し、バックアップやクリーンアップの単位が不明確だった。

## Decision
デスクトップ版の**すべてのローカルデータをホームディレクトリ配下の単一ルート `~/deskspawn/` に一元化**する（ADR-001〜006の履歴を踏まえたデスクトップ復活版の基盤決定）。

```
~/deskspawn/
├── projects/          # プロジェクト実体（<id>/）
├── templates/         # 初回展開テンプレート
├── config/            # 設定JSON
├── workspace/         # Rustワークスペース（B:問題の解消）
├── tools/             # bun等の同梱ツール
└── logs/              # sidecar/Rustログ
```

ルート解決はRust側の `engine/workspace.rs` に集約し、環境変数によるオーバーライド（`DESKSPAWN_ROOT`）もサポートする。

## Consequences
- 実行時cwd依存のB:問題が解消され、保存先が常に安定
- バックアップ・クリーンアップ・アンインストールが単一ディレクトリで完結
- 旧保存先（OPFS / previewコピー）との二重管理が解消
- 既存データは移行対象なしのため、クリーンアップのみで対応（ADR-016の廃棄決定）
