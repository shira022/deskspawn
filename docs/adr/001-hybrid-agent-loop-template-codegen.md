# ADR-001: ハイブリッドアーキテクチャの採用（Agent Loop × テンプレ駆動コード生成）

## Status
accepted

## Context
プロジェクト初期、AIによるアプリ開発プラットフォームの全体設計を検討した。既存のAI開発ツール（Bolt.diy等）のコード生成方式は、自由生成による品質ばらつきと、生成コードの検証不足が課題だった。一方、完全なテンプレート固定ではユーザーの自由度が損なわれる。

## Decision
エージェントループ（計画→実装→検証→修正）と、テンプレート駆動のコード生成を組み合わせたハイブリッド方式を採用する。生成はテンプレートを起点とし、AIが段階的に拡張する。

## Consequences
- 生成品質の安定性とユーザー自由度の両立が可能になった
- エージェントループの各フェーズをスキルとしてコード化する運用が確立
- テンプレートの保守が継続的な負担となる
